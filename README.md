# emilio-guadarrama-portfolio

Personal portfolio of Emilio Guadarrama — Electronics and Semiconductor Engineering student
at Tecnológico de Monterrey and lead designer of the IGNIS rocket flight computer.

Live site: https://emilio-guadarrama-portfolio.vercel.app

## Stack
React + Vite · React Router · Tailwind CSS · Framer Motion · i18next (EN/ES)

## Development
```bash
npm install
npm run dev      # http://localhost:5173
npm run build
```
